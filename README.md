# pairwise-gop-seek

拖进度条后画面停在关键帧，播放器只 seek 到最近 I 帧就停，后面的 P 帧没解码；开放 GOP 的 B 帧引用了上一个 GOP 的帧，seek 后花屏；时间戳按显示顺序而非解码顺序，seek 目标落在两个 B 帧之间时定位错一帧；编辑列表把片头裁掉后，容器时间戳与解码时间戳不同步，seek 偏移固定差几秒；可变帧率素材按平均帧率换算，长片越拖越偏；音频没跟着视频 seek，重新播放后口型差半秒；解码器缓存了旧参数集，切到 HEVC 片段后仍在用 AVC 的 SPS；预滚帧数按固定 25 帧，GOP 长达 10 秒时仍不够；seek 后清了参考帧但没清输出队列，前一个位置的一帧混进来；网络流只允许按分片 seek，客户端按字节偏移估算时间戳，关键帧落在分片尾部时多等一轮。media/gop_seek.py 是核心，tests/test_gop_seek.py 15个红。要修的是：seek 后解码到目标；开放 GOP 回溯前向参考；按解码序定位；编辑列表换算；按实际帧时长；音视频同步 seek；参数集重置；预滚按 GOP 长度；清空输出队列；按索引表 seek。

## 运行

```bash
python -m pytest tests -q
```
